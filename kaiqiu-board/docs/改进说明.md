# 与 Codex 版（1.4.0）相比的改进

Codex 版的思路是“Mac 用 Swift 原生壳 + Windows 另写一套 pywebview 壳 + 共用 Python 服务和手写 SVG 页面”。
这一版没有照搬，改成**一套 Python + 网页代码，两个平台各打一个原生安装包**，由 GitHub Actions 在真实的
Windows 和 macOS 机器上自动构建、启动自测后再交付。

## 一、交付与安装

| 方面 | Codex 1.4.0 | 本版 2.0.0 |
| --- | --- | --- |
| 两个平台的代码 | Mac：Swift/AppKit 壳 + 控制器脚本；Windows：另一套 pywebview 壳 + NSIS/Inno/PowerShell 三套构建脚本 | 一套代码（`kaiqiu/`），同一个入口，同一套页面 |
| Mac 应用能否拷到别的 Mac | 不能。文档写明“应用记录了打包机器的 Python 路径，需要 Python 3.11+ 重新打包” | 能。Python 和依赖都打进 .app，提供 Apple 芯片和 Intel 两个 dmg |
| Windows 安装包怎么来的 | 在 Mac 上用 NSIS 拼出来，内嵌 Windows Python；作者注明“新版 Windows 实机验收仍待确认” | 在 GitHub 的 Windows 机器上用 PyInstaller + NSIS 构建，构建后**真的启动一次**检查接口和 Excel 导出 |
| 可复现 | 依赖作者那台 Mac 的环境和路径 | 任何人推代码 → Actions 自动出三个平台的包；`python packaging/build.py` 本地也能打 |
| 端口 | Mac 版固定 8768，被其他程序占用时打不开 | 每次随机端口，不会和其他程序冲突 |
| 窗口组件缺失时 | Windows 缺 WebView2 时联网补装 | 自动改用默认浏览器打开，照样能用 |
| 源码/资源体积 | 初始数据 JSON 1.1 MB + Excel 0.9 MB | 初始数据 79 KB（紧凑格式，内容相同），Excel 导出时现生成 |

## 二、数据更新更稳

| 方面 | Codex 1.4.0 | 本版 |
| --- | --- | --- |
| 打开时是否更新 | 每次打开都全量抓 40 个接口 | 默认打开时更新，但**30 分钟内重复打开不重抓**（可设置）；还可选窗口开着时每 3/6/12/24 小时自动更新 |
| 网站返回残缺数据 | 只要格式对就覆盖 | **异常检测**：月份变少、或全国历史总人次比上次少 10% 以上，判定为来源异常，保留旧数据 |
| 网站修订了历史 | 静默覆盖，看不出来 | 每次更新后提示“新增 2026-10，网站修订了 N 个历史数值”，可点开看每一处的原值 → 新值 |
| 月初边界 | 要求最新月份必须等于当月，否则整次更新失败 | 网站还没出当月数据时也能正常更新 |
| 历史快照 | 每次保存 JSON + Excel，不清理，越用越大 | 只保留最近 12 份，自动清理 |
| 失败提示 | 一长串英文异常 | 连不上网站时一句话说明；部分失败时列出是哪几个区域 |

## 三、看板功能

| 方面 | Codex 1.4.0 | 本版 |
| --- | --- | --- |
| 图表 | 手写 SVG，固定下拉选范围 | ECharts：滚轮/拖动缩放时间轴、1/2/3/5 年/全部一键切换，每张图可**保存 PNG** |
| 页面结构 | 一个长页面往下滚 | 6 个栏目：概览、区域、年度、自定义对比、近期热度、明细 |
| 指标切换 | 月度、年度、自定义各有自己的“人次/场次”选择，容易混 | 顶部一个开关，全部页面一起切换 |
| 概览 | 全国卡片 + 趋势 + 前 12 + 列表 | 新增“近 12 个月累计及同比”“历史第几高”“同比增长最快/下降最多的区域”（自动过滤基数太小的区域）、**35 区域 × 24 个月热力图**（同比或占全国） |
| 区域 | 列表 + 趋势 | 列表里带**近 24 个月迷你走势图**、占全国比例、搜索；详情含“全国第几名”和**季节规律图**（近 4 年逐月对照） |
| 年度 | 年度柱图、同比、两年逐月 | 同样功能；不满 12 个月的年份用斜纹标出，点柱子切换年份 |
| 自定义对比 | 叠加或加总，按月/按年 | 新增**按季**、**占全国比例**、**指数化（起点=100，比较增速）**；**大区快捷选择**（华北、华东、西南……）；颜色跟着区域走，增删区域不会变色 |
| 滚动时段 | 7/30/90/365 天排行 | 新增**热度指数**（近 30 天日均 ÷ 近 365 天日均，看最近是升温还是降温）和占比 |
| 明细 | 月度历史表 | 人次和场次的环比、同比并排，外加占全国比例 |
| 深色模式 | 无 | 浅色 / 深色 / 跟随系统 |
| 缩放 | 只有 Mac 有（Swift 注入） | 两个平台都有，Ctrl/⌘ +/−/0 |
| 记住选择 | 部分 | 栏目、指标、区域、对比条件等全部记住 |

## 四、导出

| 方面 | Codex 1.4.0 | 本版 |
| --- | --- | --- |
| Excel | 9 张表 40 张图，大量公式；作者注明“openpyxl 不计算公式，未用 Excel 逐个重算” | 8 张表 3 张图，**所有增长率都是算好的数值**，用 WPS、Numbers、手机预览打开数字都一样；新增可做数据透视的长表 |
| 其他导出 | 无 | 当前页表格导出 CSV（Excel 直接打开不乱码）、每张图导出 PNG |
| 保存后 | — | 弹出“在文件夹中显示” |

## 五、安全

- 只监听 127.0.0.1；检查 Host 头（防 DNS 重绑定）、Origin，所有写操作需要每次启动随机生成的令牌，其他网页无法触发刷新或写文件。
- “在文件夹中显示”只允许打开本次保存过的文件。

## 六、测试

| | Codex 1.4.0 | 本版 |
| --- | --- | --- |
| 自动测试 | Python 22 项 + 几组 Node/Swift 脚本，在作者电脑上手动运行 | Python 21 项 + Node 8 项，每次推代码在 CI 自动跑 |
| 打包后的程序 | 手工检查 | CI 里启动打包后的程序，检查页面、图表库和 Excel 导出都能访问 |
| 真实网站 | 手工 | CI 里有一项真实访问开球网的检查（不阻塞打包） |

## 七、取舍（本版没有做的）

- **没有沿用原来 9 表 40 图的 Excel 格式**。如果你习惯那份工作簿，可以继续用 Codex 版导出；两个应用数据目录不同，可以同时安装。
- 图表的键盘逐月定位（← → Home End）没有做，鼠标悬停和拖动缩放代替。
- 安装包没有付费的代码签名（Windows SmartScreen / macOS 首次打开需要多点一下），见《安装说明》。
