# 开球网数据看板 · 安装说明

## Windows（Windows 10 / 11，64 位）

**安装版（推荐）**：双击 `KaiqiuBoard-Setup-2.0.0-x64.exe` → 下一步 → 完成。

- 装在当前用户目录，**不需要管理员权限**，不需要装 Python。
- 自动建桌面和开始菜单快捷方式“开球网数据看板”。
- 第一次运行如出现“Windows 已保护你的电脑”（SmartScreen）：点“更多信息”→“仍要运行”。这是因为安装包没有购买代码签名证书，不是病毒提示。
- 卸载：开始菜单 →“卸载开球网数据看板”，或“设置 → 应用”。卸载不会删除已下载的数据。

**免安装版**：解压 `KaiqiuBoard-2.0.0-windows-x64.zip`，双击文件夹里的 `KaiqiuBoard.exe`。

窗口使用系统自带的 WebView2（Windows 11 和更新过的 Windows 10 都有）。如果电脑上没有，程序会自动改用默认浏览器打开，功能一样。

## macOS（macOS 11 及以上）

1. 按芯片选择安装包（左上角  → 关于本机）：
   - Apple 芯片（M1/M2/M3/M4）：`KaiqiuBoard-2.0.0-macOS-arm64.dmg`
   - Intel 芯片：`KaiqiuBoard-2.0.0-macOS-x86_64.dmg`
2. 双击 dmg，把“开球网数据看板”拖进“应用程序”。
3. **第一次打开**：在“应用程序”里**右键**（或按住 Control 点按）→“打开”→ 再点“打开”。之后双击即可。
   - 如果提示“已损坏，无法打开”：打开“终端”，运行
     `xattr -cr "/Applications/开球网数据看板.app"`，再双击打开。
   - 原因同 Windows：没有付费的 Apple 开发者签名和公证，系统会拦截一次。

## 使用

- 打开即显示上次的数据，并在后台自动从开球网更新全部历史（约 10–60 秒，顶部有进度）。
  半小时内重复打开不会再抓一遍（可在 ⚙ 设置里改）。
- 顶部切换：概览 / 区域 / 年度 / 自定义对比 / 近期热度 / 明细；右上切换“参赛人次 / 比赛场次”。
- 导出：右上“导出”→ 完整 Excel 报表，或当前页表格（CSV）；每张图右上角 ⤓ 可保存 PNG 图片。
- 缩放：Ctrl/⌘ 加号、减号、0。外观可选浅色 / 深色 / 跟随系统。
- 关闭窗口即退出，后台不会残留。

## 数据存在哪里

| 系统 | 目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\KaiqiuBoard` |
| macOS | `~/Library/Application Support/KaiqiuBoard` |

里面是最近 12 次成功更新的快照、设置和日志（`kaiqiu.log`）。⚙ 设置里有“打开数据文件夹”按钮。
本应用和 Codex 版“开球网数据看板”的数据目录不同，可以同时安装，互不影响。
